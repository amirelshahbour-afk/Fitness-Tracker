# Fitness Tracker

تطبيق شخصي بالعربية لمتابعة التمارين والتغذية وقياسات الجسم.

- تسجيل التمارين بالتاريخ والمجموعة العضلية والأوزان والعدات، بثلاث جولات.
- إضافة وتعديل وحذف الوجبات والقياسات والتمارين.
- ملخص تغذية حسب اليوم: السعرات والبروتين والكربوهيدرات والدهون.
- رسم لتطور الوزن وأهداف وزن وتغذية قابلة للتعديل.
- لا توجد بيانات تجريبية في السجل الجديد. القياسات الإضافية اختيارية.
- تصدير واستيراد نسخة JSON احتياطية.

## الخصوصية والحفظ
البيانات محفوظة في LocalStorage على نفس المتصفح والجهاز؛ لا توجد مزامنة تلقائية بين الأجهزة. تصدير النسخ الاحتياطية مهم قبل مسح بيانات المتصفح أو الانتقال إلى جهاز آخر. استيراد نسخة يستبدل السجل بعد تأكيد المستخدم. القيم الغذائية يتم إدخالها يدويًا.

## التشغيل
قدّم ملفات المشروع عبر خادم ويب ثابت. لا توجد تبعيات أو خطوة بناء. يمكن إضافة الرابط إلى الشاشة الرئيسية من Safari. الاستضافة الخاصة تحتاج تسجيل الدخول بالحساب المصرح له.

## التحقق
تم فحص صياغة JavaScript وروابط الأصول وملف manifest، واختبار منطق الحالة الفارغة والتواريخ والمجاميع والحفظ والإضافة والتعديل وهروب النصوص. لم يُنفذ اختبار متصفح مرئي.
