# Fitness Tracker

تطبيق شخصي لمتابعة التمارين والتغذية وقياسات الجسم.

## النسخة الأولى
- Dashboard للوزن وBMI والدهون والعضلات والماء وBMR.
- سجل تاريخي للقياسات مع رسم لتطور الوزن.
- تسجيل التمارين والمجموعات والأوزان والعدات.
- تسجيل الوجبات والسعرات والبروتين والكربوهيدرات والدهون.
- تخزين محلي على الجهاز باستخدام LocalStorage.
- PWA قابلة للإضافة إلى شاشة iPhone الرئيسية.

## التشغيل
افتح `index.html` عبر خادم ويب أو فعّل GitHub Pages للفرع `main`.

> البيانات الصحية المعروضة للمتابعة الشخصية وليست تشخيصًا طبيًا.
